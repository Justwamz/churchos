# Changing your payout account

Changing where money is paid is a high-risk action, so it has extra protection.

## Who can do it
Only the **organisation owner** can see or change payout accounts.

## How it works
1. The owner requests the new account for a branch.
2. A ChurchOS reviewer approves or rejects it.
3. After approval there is a **72 hour cooling-off period**. Until it ends, payouts keep going to the old account.
4. Then the new account takes over automatically.

The waiting period gives you time to spot a request you did not make. If you see one, contact ChurchOS straight away.
