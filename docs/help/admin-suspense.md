# Working the suspense queue

A payment lands in suspense when its church code is missing, wrong or unknown.

## What you can do
- **Assign to branch** credits the payment to a church. The 48 hour hold starts at that moment.
- **Do nothing.** After 48 hours the next settlement run refunds the sender automatically, less non-refundable network charges.

## Rules
- Suspense money is never paid out to a church.
- Check the sender's phone and the typed reference before assigning, for example a one-letter typo of a real code.
- If the sender contacts you first, handle it as a reversal request instead.
