# Paying by paybill and the church code

You can also give by sending money to the ChurchOS paybill instead of using the prompt.

## What to type as the account number
Use your church code, a hash sign, and what you are giving for. For example:
- `GRC001#TITHE` for tithe at church GRC001
- `GRC001#OFFERING` for an offering
- `GRC001#PROJ-ROOF` for a project with the code ROOF

Capital or small letters both work. Spaces around the code are ignored.

## What if I type it wrongly?
If the church code is missing or wrong, ChurchOS cannot tell which church the money is for. The money is **not lost**. It is held safely in a holding account. You can ask for it back, see **I paid the wrong church**, or the church can claim it. If nobody claims it within 48 hours it is refunded to you, less any charges the mobile network already took.
