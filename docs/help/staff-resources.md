# Setting up what can be booked

A **resource** is anything members can ask to book: a **person** (a pastor or an official), a **place** (a hall, the grounds) or a **thing** (a projector, a bus).

## Add one
1. Open **Resources** and choose **New resource**.
2. Choose whether it is a person, place or thing, give it a name and a short description. For a person, choose whose diary it is. They can answer their own requests.
3. Choose the branch it belongs to, or the whole church if you manage every branch.
4. Set the **hours**: for each day, the times it can be booked. Add a break for lunch by adding a second range.
5. Set the **booking length**. People book in blocks of this size, for example 30 minutes for a pastor and 60 minutes for a hall. You can also set the longest booking, a **minimum notice** (for example 24 hours) and how far ahead it can be booked.
6. Choose how requests are answered: **someone says yes** (recommended for halls and people) or **approved automatically** (good for equipment).
7. Optionally set a **price**, for the whole booking or per hour. Leave it empty for free.

## Prices
A priced booking waits for payment after it is approved and holds the time for 24 hours. If nobody pays, the time is released. Payment goes through the normal giving flow, so the platform fee applies like any other payment.

## Blocked times
Use **Blocked times** for leave, repairs or services. Nobody can book a blocked time. You cannot block a time that already has a booking, so cancel that booking first.

## Switching off
**Switch off** hides a resource from members straight away. Existing bookings stay. Every change is in the audit log.
