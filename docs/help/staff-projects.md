# Projects, restricted funds and pledges

## Create a project
Give it a name, a short code such as `ROOF`, a target amount, and an optional deadline. Members then see it on the giving page.

## Restricted funds
Tick **Restricted fund** when the money must be spent only on that project. Reports then show the balance for restricted projects separately from general funds.

## Pledges
Members can pledge an amount and pay over time. Open a project to see each pledge, how much has been paid, and what is left.

## Send reminders
Use **Send reminders** on a project to remind members whose pledge is not fully paid. Reminders always appear in the member's app. They also go by SMS if your church has SMS credit. See *The SMS wallet*.
