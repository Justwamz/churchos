# Reviewing church verification documents

## What to check
- **Registration certificate:** the name matches the church applying.
- **KRA PIN certificate:** the PIN belongs to the same organisation.
- **Signatory ID:** a valid ID for a person authorised to act for the church.
- **Payout proof:** the account name matches the church, and the account is the one on the payout settings.

## Approve or reject
Open each document and approve it, or reject it with a clear reason. The church sees your reason, so say exactly what to fix.

## When a branch becomes payable
A branch is paid out only when the registration certificate, KRA PIN, at least one signatory ID and that branch's payout proof are all approved. The newest document of each type is the one that counts.
