# Setting fees for a church

## Who pays
**Church absorbs** takes the fee from each gift. **Member pays on top** adds the fee to what the member pays, so the church receives the full gift.

## Platform fee
- **Flat:** one rate for every gift.
- **Tiered:** the rate depends on the size of the gift. The tier is chosen by the amount of the transaction as a whole, not in slices.

Rates are in basis points: 100 basis points is 1%, so 150 is 1.5%.

## Provider costs
Each payment method has its own cost, as a percentage plus an optional fixed amount. The live preview shows the member's total, the platform fee, the provider cost and the church's net.

The church sees one combined fee. Only the admin console shows the split.
